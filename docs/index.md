# Orchestra Provider

[Orchestra](https://www.getorchestra.io) is a unified control plane for data and AI workflows. This provider lets you
define your Orchestra workspace in Terraform, so it is reviewed, versioned and promoted like the rest of your
infrastructure.

| Area | What you can manage |
|---|---|
| Pipelines | `orchestra_pipeline`, written in HCL or loaded from pipeline YAML with the `pipeline_yaml` function |
| Environments and connections | `orchestra_environment`, `orchestra_integration_connection` |
| Data quality and alerting | `orchestra_monitor`, `orchestra_monitor_order`, `orchestra_incident_settings` |
| AI | `orchestra_agent`, `orchestra_skill` |

Data sources read existing pipelines, environments, connections, monitors, assets and skills, so you can reference
what is already in the workspace.

## Getting started

1. Create an API key under [Settings → API Keys](https://app.getorchestra.io/settings/workspace).
2. Export it as `ORCHESTRA_API_KEY`, or pass it as `api_key`.
3. Configure the provider, then work through one of the guides in the sidebar.

## Example Usage

```terraform
terraform {
  required_providers {
    orchestra = {
      source = "orchestra-hq/orchestra"
    }
  }
}

# The API key can also come from the ORCHESTRA_API_KEY environment variable,
# which is the usual choice in CI.
provider "orchestra" {
  api_key = var.orchestra_api_key
}

variable "orchestra_api_key" {
  description = "Orchestra workspace API key, from Settings -> API Keys."
  type        = string
  sensitive   = true
}
```

## Schema

### Optional

- `account_id` (String) Act on this account rather than the one the credential resolves to, sent as the `X-Orchestra-Account-Id` header. Falls back to the `ORCHESTRA_ACCOUNT_ID` environment variable. An API key is issued to a single account, so it may only name that account.
- `api_key` (String, Sensitive) Orchestra workspace API key. Falls back to the `ORCHESTRA_API_KEY` environment variable. Find it under [Settings → API Keys](https://app.getorchestra.io/settings/workspace).
- `base_url` (String) Base URL for the Orchestra API server. Falls back to the `ORCHESTRA_BASE_URL` environment variable, then `https://app.getorchestra.io/api/engine/public`. Must use `https://`. Agents and skills use the Agents API beside it, at `/api/ai/v1` on the same host.
